# Laravel

Es un framework PHP orientado al desarrollo de aplicaciones web y APIs.

Proporciona herramientas para autenticación, bases de datos, validación de formularios y organización del código.

## Crear proyecto

```bash
composer create-project laravel/laravel backend
```

## Ejecutar servidor

```bash
php artisan serve
```

## Ejecutar migraciones

```bash
php artisan migrate
```

## Crear controlador

```bash
php artisan make:controller NombreController
```

## Crear modelo

```bash
php artisan make:model NombreModelo
```
