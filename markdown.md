# Markdown

Markdown es un lenguaje de marcado ligero que permite dar formato a texto plano de manera sencilla y legible.

Se utiliza habitualmente en README, documentación, Issues y Wikis de GitHub.

## Título principal

```markdown
# Mi Proyecto
```

## Subtítulo

```markdown
## Instalación
```

## Lista

```markdown
- Elemento 1
- Elemento 2
- Elemento 3
```

## Lista numerada

```markdown
1. Paso uno
2. Paso dos
3. Paso tres
```

## Enlace

```markdown
[GitHub](https://github.com)
```

## Imagen

```markdown
![Descripción](imagen.png)
```

## Código en línea

```markdown
`npm install`
```

## Bloque de código

````markdown
```bash
npm install
npm run dev
```
````

## Casilla de tarea

```markdown
- [ ] Pendiente
- [x] Completado
```

## Ejemplo de README

```markdown
# Nombre del proyecto

## Descripción

Breve descripción del proyecto.

## Tecnologías

- React
- Node.js

## Instalación

npm install

## Integrantes

- Nombre Apellido
```
