# GitHub Web

GitHub Web permite editar archivos directamente desde el navegador sin instalar Git, SSH, Node.js, Python ni otras herramientas.

Es una buena alternativa para computadoras compartidas o cuando se necesita realizar cambios rápidos.

## Abrir el editor web

1. Ingresar al repositorio.
2. Presionar la tecla:

```text
.
```

(punto)

GitHub abrirá automáticamente el editor web.

## Funcionalidades disponibles

* Editar archivos.
* Crear archivos nuevos.
* Eliminar archivos.
* Navegar el repositorio.
* Crear commits.
* Revisar cambios.
* Utilizar terminal integrada (según disponibilidad).

## Flujo habitual

```text
Abrir repositorio
↓
Presionar "."
↓
Editar archivos
↓
Commit
↓
Guardar cambios en GitHub
```

## Cuándo puede resultar útil

* Computadoras del aula.
* Equipos sin permisos de instalación.
* Correcciones rápidas.
* Documentación y README.
* Cambios pequeños de código.

## Consideraciones

GitHub Web no reemplaza completamente un entorno de desarrollo local.

Para proyectos grandes o cuando se necesitan herramientas específicas (Docker, bases de datos, compilación, etc.) se recomienda trabajar desde una computadora personal.

## Recurso útil

```text
Repositorio
↓
Presionar "."
↓
Editor Web
```

Es una de las formas más rápidas de comenzar a colaborar en un proyecto alojado en GitHub.
