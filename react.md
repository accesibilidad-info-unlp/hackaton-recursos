# React

React es una biblioteca de JavaScript para construir interfaces de usuario interactivas.

Es una opción popular para desarrollar aplicaciones web modernas y permite organizar la interfaz en componentes reutilizables.

## Crear proyecto

```bash
npm create vite@latest frontend
```

## Instalar dependencias

```bash
npm install
```

## Ejecutar entorno de desarrollo

```bash
npm run dev
```

## Generar versión de producción

```bash
npm run build
```

## Vista previa de producción

```bash
npm run preview
```
