# Hackatón 2026 - Recursos rápidos

Estos ejemplos son puntos de partida para ayudar a resolver bloqueos frecuentes durante la hackatón.

No es necesario utilizar todas las tecnologías ni seguir exactamente estas configuraciones.

El objetivo es ayudar a que los equipos puedan concentrarse en resolver problemas y desarrollar sus proyectos.

## Contenido

* Docker
* Python
* React
* Laravel
* Nginx
* Apache
* Accesibilidad Web
